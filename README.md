# Ritvik's Futuristic Hub

Build a world-class, hyper-modern, developer portfolio website for "Ritvik Jadhav", who is a Web Developer. The design must look exceptionally premium, polished, and futuristic, standing out from standard template portfolios.



### 1. Color Palette & Theme (Dark Mode First)

- Primary Background: Deep obsidian/space black (#09090b or #030712) with subtle, animated glowing radial gradients (deep violet and electric blue) in the background.

- Accent Colors: Electric Cyan (#06b6d4) for highlights, Neon Indigo (#6366f1) for secondary elements, and vibrant Emerald (#10b981) for online status and success states.

- Text: Crisp white (#f8fafc) for headings, and muted slate gray (#94a3b8) for body text.



### 2. Visual Style & Advanced UI (Glassmorphism & Graphics)

- Glassmorphism: Use heavy frosted-glass cards (backdrop-filter: blur(16px), background: rgba(255, 255, 255, 0.03), border: 1px solid rgba(255, 255, 255, 0.08)) for sections, navbars, and project cards.

- Graphics & Glows: Add subtle glowing borders on hover, grid-pattern backgrounds, glowing gradient orbs that subtly drift behind elements, and glowing tech-stack badge pills.

- Typography: Clean, modern sans-serif fonts (like Inter or Plus Jakarta Sans) with gradient text effects on the main headings.



### 3. Smooth Animations & Micro-Interactions

- Smooth entrance animations (fade-in, slide-up with staggered delays) for sections as the user scrolls.

- Interactive hover states: Cards should subtly scale up and tilt or project a neon glow when hovered over.

- Smooth scroll behavior across all anchor links.



### 4. Layout & Required Sections (Fully Working Components)



- **Top Navigation Bar (Sticky Glassmorphic):**

  - Left: Logo/Name "Ritvik Jadhav" with a pulsing green "Available for hire" dot.

  - Right: Links to sections (About, Skills, Projects, Experience, Contact) + a glowing "Resume" button.



- **Hero Section:**

  - Eye-catching headline with gradient text: "Hi, I'm Ritvik Jadhav — Crafting Scalable Web Experiences & Immersive Interfaces."

  - Subtext: BSc IT Student & Passionate Full-Stack Web Developer.

  - Call-to-Action buttons: "Explore Projects" (primary glowing button) and "Get in Touch" (glass outline button).

  - An interactive live code/terminal graphic widget or floating tech badges on the side.



- **About Me Section:**

  - Professional bio highlighting your background in IT, passion for clean UI/UX design, real-time networking, and modern frontend/backend architectures.

  - Quick stat counters (e.g., Projects Built, Technologies Mastered, Code Commits).



- **Technical Skills Matrix (Categorized & Interactive):**

  - Interactive tabs or grouped cards with glowing icons/logos for:

    - Frontend: React, Next.js, Tailwind CSS, TypeScript, HTML/CSS.

    - Backend & Realtime: Node.js, Express, Supabase, PostgreSQL, WebSockets.

    - Tools & DevOps: Git, GitHub, Docker, VS Code, Vercel, Figma.



- **Projects Section (The Portfolio Core):**

  - Interactive filter buttons (All, Full-Stack, E-Commerce & UI, Real-Time).

  - Project Cards featuring:

    - **Project 1: Emerial – Luxury Watch E-Commerce Platform**

      - Description: An ultra-luxurious e-commerce web application (`emerial.vercel.app`) designed with high-end typography, minimalist dark-mode aesthetics, smooth product showcases, and responsive layouts.

      - Tech Stack: React, Tailwind CSS, Vercel.

      - Links: Live Demo (`https://emerial.vercel.app`), GitHub Repo, and interactive preview tags.

    - **Project 2: WhatsApp-Style Real-Time Chat App**

      - Description: Full-stack messaging platform featuring database persistence, real-time WebSocket sync, and optimistic UI updates.

      - Tech Stack: Supabase, PostgreSQL, React, WebSockets.

    - **Project 3: Decentralized P2P Mesh Chat (Bitchat Concept)**

      - Description: Local browser-based peer-to-peer communication concept inspired by offline mesh networking frameworks.



- **Experience & Education Timeline:**

  - Clean vertical timeline showing BSc IT milestones, key academic projects, and self-taught engineering milestones.



- **Working Contact Section:**

  - A fully functional contact form with input fields for Name, Email, and Message. 

  - Add validation and a success state toast/alert message when the user clicks "Send Message".
